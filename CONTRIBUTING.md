# Contributing

Thanks for your interest in OpenVision. The project is an experimental phone-based vision assistant with ESP32-CAM hardware.

## Before opening a change

- Search existing issues and pull requests.
- Keep changes focused and explain the problem they solve.
- Do not include credentials, private network details, personal images, model weights, or generated build/media files.
- For hardware changes, include the board/sensor revision, wiring, and measurements where possible.
- For app changes, include browser/device details and steps to reproduce.

## Validation

- Serve the app over HTTP or HTTPS; do not rely on opening the HTML file directly.
- Test on the target Android browser and record exact device/browser/model details.
- Bench-test firmware and power before wearing hardware.
- Never describe untested hardware or accessibility behavior as verified.

## Pull requests

Describe the motivation, implementation, testing performed, known limitations, and any hardware or documentation impact. Keep safety and privacy implications explicit.
